
# Smart Recipe Preparation Agent

## Overview
Smart Recipe Preparation Agent is an AI-powered web application that recommends recipes based on ingredients available at home. The application uses IBM watsonx AI and Streamlit to generate recipe suggestions, cooking instructions, nutrition insights, and ingredient substitutions.

## Features
- AI Recipe Generation
- Ingredient-Based Recipe Recommendations
- Nutrition Insights
- Ingredient Substitutions
- Food Waste Reduction
- Interactive User Interface

## Technologies Used
- Python
- Streamlit
- IBM watsonx AI
- IBM Granite Foundation Models
- JSON

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Project Goal
To help users prepare meals using available ingredients while leveraging Generative AI for personalized recipe recommendations.
